# WPSApp عربي — مشروع أندرويد أولي

تطبيق أندرويد أصلي بلغة Kotlin لفحص معلومات شبكات Wi‑Fi القريبة ضمن الصلاحيات التي يسمح بها النظام.

## الميزات الحالية
- واجهة عربية واتجاه من اليمين إلى اليسار.
- طلب أذونات Wi‑Fi والموقع اللازمة حسب إصدار أندرويد.
- عرض اسم الشبكة (SSID)، مستوى الإشارة، نوع الحماية، وتردد الشبكة عند إتاحة البيانات.
- تحديث قائمة الشبكات يدوياً.
- رسائل واضحة عند رفض الأذونات أو عندما يمنع النظام الفحص.

## حدود مهمة
- لا يحتاج التطبيق إلى Root.
- لا يحاول تخمين كلمات المرور أو تجاوز حماية الشبكات.
- أندرويد قد يقيّد فحص الشبكات أو يبطئه، وقد يتطلب تشغيل خدمات الموقع حتى لو لم يعرض التطبيق موقعك.
- لا يمكن ضمان عرض كل الشبكات أو كل المعلومات على جميع الأجهزة؛ سلوك Wi‑Fi يختلف حسب إصدار أندرويد والشركة المصنّعة.
- هذا مشروع مصدر أولي؛ لم يتم اختباره بعد على جهاز المستخدم.

## إنشاء APK عبر GitHub من الهاتف
1. أنشئ مستودعاً جديداً على https://github.com/new باسم `wpsapp-arabic`.
2. ارفع محتويات هذا المجلد إلى المستودع (لا ترفع ملف ZIP فقط إذا أردت تشغيل GitHub Actions).
3. افتح تبويب **Actions** وفعّل Actions إذا طلب منك GitHub ذلك.
4. شغّل workflow المسمى **Build Android APK**.
5. بعد نجاحه، افتح نتيجة التشغيل ونزّل artifact المسمى `wpsapp-debug-apk`.

يمكن فتح المشروع في Android Studio لاحقاً لبنائه أو تطويره.
